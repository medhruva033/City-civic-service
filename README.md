# City Civic Service Management System

A full-stack web application designed to help citizens report civic issues, track complaints, and connect with municipal departments for faster issue resolution.

## 🚀 Project Overview

The City Civic Service Management System provides a centralized platform for managing local civic complaints such as potholes, garbage collection, water supply issues, and damaged streetlights.

The platform connects citizens, municipal staff, and administrators through a single digital system.

## 👥 User Roles

- **Citizen:** Register, submit complaints, upload photos, and track complaint status.
- **Staff:** View assigned complaints, update progress, and resolve issues.
- **Admin:** Manage users, assign complaints, monitor activities, and view analytics.

## ✨ Key Features

- User registration and login
- Role-based access control
- Civic complaint submission
- Complaint tracking and status history
- Staff assignment and management
- Admin dashboard and analytics
- Responsive user interface

## 🎯 Project Objectives

- Digitize civic complaint management.
- Improve communication between citizens and municipal departments.
- Increase transparency in complaint resolution.
- Reduce manual complaint management.
- Provide efficient monitoring and reporting.
