# NEXUS – Personal Command Center

A futuristic personal productivity dashboard built using
HTML, CSS and Vanilla JavaScript.

## Features

- Real-time digital clock
- Automatic greeting
- Live weather using Open-Meteo API
- Interactive task manager
- Add, complete and delete tasks
- LocalStorage task persistence
- Productivity statistics
- 25-minute Pomodoro focus timer
- Dark and light themes
- Responsive dashboard
- Glassmorphism UI
- Animated gradients and hover effects

## Technologies

- HTML5
- CSS3
- JavaScript ES6+
- Open-Meteo API
- Lucide Icons
- LocalStorage
